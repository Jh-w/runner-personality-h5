## 1. v4.2.5 → v4.3 变更清单

市场调研报告对 v4.2.5 的 32 型动物方案进行了交叉验证。基于报告的 5 条关键建议，v4.3 的变更分三类：

### ✅ 保留（市场调研验证通过的设计）

1. **32 型 + 5 维度体系**：报告确认 32 型在内容精度上合理（覆盖真实跑者差异），且在竞品矩阵中构成差异化优势——32 型的分类粒度 + 32 动物视觉系统是竞品中独一无二的。
2. **18 题题库**：对标 SBTI 的 12-16 题、3-5 分钟体验，v4.3 在「不太多让用户放弃」和「不太少让人觉得没深度」之间取得平衡。3 题/维度的设计恰好达到竞品调研报告推荐的最低信度门槛。
3. **动物角色体系（无性别）**：被定性为「防御性护城河」——规避性别争议、扩大受众覆盖面。32 种动物映射表的设计逻辑（气质匹配 + 匹配理由文案桥接）被认可。
4. **脱口秀式文案格式**（Hook + 180-250 字脱口秀 + 5 维度段子 + 社交标语 + 荒诞标签）：与市场调研「正经框架 + 不正经内容 = 最优传播配方」的判断一致。
5. **风味标签独立设计**（时间偏好/伤痛态度/饮食关系 3 题不计入 32 型分类）：个性化感知策略被认可。

### 🔄 变更（需调整的设计）

1. **传播符号去编码化**：v4.2.5 中用户可见「CSGP_D」等 32 型编码。v4.3 严格执行：用户侧所有界面（结果页/分享卡片/图鉴）**仅显示「猎豹型」**，编码 CSGP_D 仅用于后台数据库和数据分析，对用户完全不可见。
2. **动物认知度筛查**：报告识别园丁鸟（Bowerbird）、极乐鸟（Bird of Paradise）、信天翁（Albatross）为低认知度物种。v4.3 在 7 月中旬内测阶段增加动物名称认知度快速问卷，低认知度动物考虑替换为更大众物种（备选池需准备）。
3. **动物插图格式最终确认**：v4.2.5 含附录 C 的 AI 作图提示词（已废弃的旧方案）。v4.3 明确交付物为 32 个扁平几何风格静态 PNG（512×512px，1:1，透明背景），移除所有 AI 作图提示词引用。

### 🆕 新增

1. **内测验证计划**：7 月中旬前完成 ≥50 名跑者共鸣度测试（1-5 分制）。验收标准：共鸣度中位数 ≥4.0 且「无法区分类型」反馈 ≤20%。不达标→触发 B 计划。
2. **B 计划（16 型 Fallback）**：从 32 型动物池中预选 16 种高认知度物种，复用部分已有文案。v4.2.5 PRD 的 16 型核心人格文案积累作为回退基础。
3. **发布窗口锁定**：2026 年 9 月（北马/上马秋季赛季窗口），工作日午间 11:30-13:00。

## 2. v4.3 MVP 范围定义

### P0 必须交付（没有这些不能上线）

| # | 交付物 | 规范 | 依赖 |
|---|--------|------|------|
| 1 | **32 型人格文案** | 32 型 × 完整文案（Hook + 脱口秀 180-250 字 + 5 维度段子各 1 句 + 社交标语 ≤15 字 + 荒诞标签 3-5 个），录入 `personalities.ts` | v4.2.5 第 4 章已完成 |
| 2 | **18 题题库** | 15 计分题 + 3 风味题，录入 `questions.ts`，每维度 3 题，每题 4 选项 | v4.2.5 第 3 章已完成 |
| 3 | **5 维计分引擎** | `calculateResult.ts` 从 4 维升级到 5 维，含风味标签独立判定逻辑 | 需开发 |
| 4 | **32 动物 PNG 插图** | 扁平几何风格，512×512px，1:1 正方形，背景透明，6 色系统，存放 `h5/public/animals/animal-type-{01~32}.png` | 需设计资源 |
| 5 | **结果页** | 按 v4.2.5 第 6.2 节布局：动物插图 → 人格名（仅中文，无编码）→ Hook → 脱口秀解读 → 5 维度段子 → 风味标签卡片（3 张）→ 分享按钮 → 公众号引导 | 需前端开发 |
| 6 | **分享卡片** | Canvas 生成，1080×1440px，含动物插图、人格名、Hook、5 维度标签条、风味标签角标、二维码。**不含 32 型编码** | 需前端 + 设计 |
| 7 | **风味标签个性化** | 3 维度 × 4 取值 = 12 条卡片文案，动态组合展示在结果页 | 文案已有，需前端渲染 |
| 8 | **传播符号去编码化** | 全用户界面零编码露出——结果页、分享卡片、图鉴、所有传播物料仅显示中文人格名（如「猎豹型」） | 需全局检查 |
| 9 | **移动端适配** | H5 响应式，微信内置浏览器兼容，iOS Safari + Android Chrome | 需前端 |
| 10 | **备用域名 + 图片分享路径** | 应对微信外链政策风险（市场调研报告风险 #4，概率 35%） | 需运维 |

### P1 建议交付（有则显著增强，无则不影响核心体验）

| # | 交付物 | 说明 |
|---|--------|------|
| 1 | **32 型动物图鉴海报** | 8×4 网格，每格 = 动物插图 + 人格名 + Hook，用于公众号封面/落地页 Hero/朋友圈长图 |
| 2 | **公众号导流组件** | 结果页底部「关注跑步人格测试公众号，获取完整 32 型解读」，含二维码/跳转链接 |
| 3 | **传播钩子文案矩阵** | 个人分享/跑团接龙/对比话题/风味标签 4 种场景的预置分享文案 |
| 4 | **动物认知度替换备选池** | 为内测中低认知度动物（园丁鸟/极乐鸟/信天翁）准备 3-5 个备选动物 |

### P2 本期不做（明确排除）

以下功能在 v4.3 MVP 中**明确不做**，避免范围蔓延：

| # | 不做项 | 原因 |
|---|--------|------|
| 1 | **社交匹配**（「你和 XX 型的兼容度」） | 市场调研报告标注「🔜 计划中」但非 MVP 必需；需用户量 ≥10 万后方有意义 |
| 2 | **用户系统**（登录/注册/历史记录） | 增加使用摩擦，与「无需登录即可测试」的设计原则冲突 |
| 3 | **数据分析后台** | MVP 阶段通过第三方埋点（如百度统计/Google Analytics）满足基本数据需求 |
| 4 | **AI 生成个性化结果** | 32 型文案已为预制内容，AI 动态生成引入质量不可控风险和 API 成本 |
| 5 | **多语言版本** | 英文动物名已在映射表中预留，但完整多语言翻译为 P2+ |
| 6 | **跑团排行榜/团队功能** | 需用户系统支撑，属于社交匹配的延伸 |
| 7 | **IP 授权/周边商城** | 市场调研报告指出需用户规模 ≥200 万后方可评估 |
| 8 | **视频/动画结果页** | 静态 PNG + 文字结果页已满足 MVP 需求，动画增加加载时长与开发成本 |

## 3. 验收标准

按用户完整体验路径（首页 → 答题 → 计算 → 结果 → 分享），每个节点的可量化验收标准如下。

### 3.1 首页

| 验收项 | 标准 | 测量方式 |
|--------|------|----------|
| 页面加载 | 首屏完整渲染 ≤2 秒（4G 网络） | Lighthouse / 真机测试 |
| 视觉元素 | 32 型动物图鉴缩略图或 Hero 视觉展示正确，无图片裂图 | 人工走查 |
| CTA 按钮 | 「开始测试」按钮点击响应 ≤200ms | 真机测试 |
| 微信兼容 | iOS 微信内置浏览器 + Android 微信内置浏览器均正常显示 | 真机测试 ≥5 款机型 |

### 3.2 答题

| 验收项 | 标准 | 测量方式 |
|--------|------|----------|
| 题目完整性 | 18 题全部展示，每题 4 选项，无缺字/乱码/排版错位 | 人工走查 |
| 答题时长 | 中位答题时长 3-4 分钟（对标 SBTI 竞品体验） | 埋点统计 |
| 完成率 | 18 题完成率 ≥85%（进入答题页后完成全部 18 题的比例） | 埋点漏斗 |
| 选项交互 | 点击选项即时高亮，再次点击可取消/修改（提交前） | 真机测试 |
| 进度展示 | 进度条或数字进度（如「第 5/18 题」）实时更新 | 真机测试 |
| 文案无错别字 | 18 题 × 4 选项 = 72 条文案，错别字数 = 0 | 人工校对 + 跑友内测 |

### 3.3 计算

| 验收项 | 标准 | 测量方式 |
|--------|------|----------|
| 计算正确性 | 32 型映射逻辑正确率 100%（5 维度 × 二元判定 = 2⁵ = 32 型全覆盖，所有组合路径可溯源） | 单元测试覆盖 32 条路径 |
| 风味标签判定 | 3 个风味维度独立判定，不影响 32 型分类，正确率 100% | 单元测试 |
| 计算响应 | 提交最后一题到结果页展示 ≤1.5 秒 | 真机测试 |
| 边界条件 | 所有选项选同一极端（如全部选「数据派」方向）不导致崩溃或空结果 | 自动化测试 |

### 3.4 结果页

| 验收项 | 标准 | 测量方式 |
|--------|------|----------|
| 32 型文案完整性 | 32 型 ×（Hook + 脱口秀 180-250 字 + 5 维度段子各 1 句 + 社交标语 + 荒诞标签 3-5 个）= 全部无空字段 | 自动化校验 |
| 文案无错别字 | 32 型完整文案错别字数 = 0（约 32×300 = 9600 字总量） | 人工校对 + 内测跑者反馈 |
| 动物插图匹配 | 32 型各显示对应动物 PNG，无错配（如 #1 猎豹图不能出现在 #2 孔雀结果中） | 自动化测试 |
| 传播符号去编码化 | 结果页全文零编码出现——搜索「CSGP」「CGLP」「EGSP」「EMLS」等 32 型编码字符串，命中数 = 0 | 自动化文本扫描 |
| 风味标签卡片 | 3 张风味卡片均展示且文案匹配用户选择（如选 A 在第 2 题 → 显示「晨型」卡片） | 自动化测试 + 人工验证 |
| 分享按钮 | 点击「生成我的跑步人格分享给跑友」→ Canvas 生成成功，成功率 100%（32 型各测试 1 次） | 自动化截图测试 |
| 再测一次 | 点击「再测一次」→ 回到第 1 题，所有状态重置 | 真机测试 |

### 3.5 分享卡片

| 验收项 | 标准 | 测量方式 |
|--------|------|----------|
| 卡片生成 | Canvas 渲染成功率 100%，32 型各生成一次无报错 | 自动化测试 |
| 卡片内容 | 含动物插图、人格名（仅中文）、Hook、5 维度标签条、风味标签角标、二维码——无编码 | 人工走查基准卡片 |
| 卡片尺寸 | 1080×1440px（3:4 竖版），文件大小 ≤500KB（PNG/JPEG） | 技术验证 |
| 微信长按识别 | 分享卡片在微信中长按可识别二维码 | 真机测试 |
| 无编码水印 | 卡片中不出现 CSGP_D 等任何编码——自动化扫描命中数 = 0 | 自动化文本扫描（OCR 或元数据检查） |

### 3.6 全局

| 验收项 | 标准 | 测量方式 |
|--------|------|----------|
| 内测共鸣度 | ≥50 名跑者，共鸣度中位数 ≥4.0（1-5 分制），「无法区分类型」反馈 ≤20% | 问卷回收统计 |
| 动物认知度 | 32 种动物认知度快速问卷，低认知度（<60% 受试者认识）动物识别并制定替换方案 | 问卷统计 |
| B 计划就绪 | 16 型动物方案（16 种高认知度动物 + 文案）完成预准备，可在 1 周内切换上线 | 文档 + 代码就绪检查 |
| 发布窗口 | 2026 年 9 月（北马/上马秋季赛季），具体发布日期由运营排期确认 | 日历对齐 |
