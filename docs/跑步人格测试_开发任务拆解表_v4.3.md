**具体操作**：

2. `signKey()` 从 4 字母变成 5 字母（`${c1}${c2}${c3}${c4}_${c5}`）
3. `matchPersonality()` 签名不变，内部使用新的 signKey 查询 32 型映射
4. `calculateResult()` 逻辑不变（答案数检查从 `<12` 变为 `<15` — 见 T4）
5. `getSignToTypeId()` 惰性构建 32 型查找表

**关键代码变更**：
```typescript
// signKey 从
function signKey(scores: DimensionScores): string {
  const c1 = scores.motivation < 0 ? 'C' : 'E';
  const c2 = scores.social < 0 ? 'S' : 'G';
  const c3 = scores.style < 0 ? 'D' : 'P';
  const c4 = scores.ritual < 0 ? 'G' : 'M';
  return `${c1}${c2}${c3}${c4}`;
}

// 变为
function signKey(scores: DimensionScores): string {
  const c1 = scores.motivation < 0 ? 'C' : 'E';
  const c2 = scores.social < 0 ? 'S' : 'G';
  const c3 = scores.style < 0 ? 'D' : 'P';
  const c4 = scores.ritual < 0 ? 'G' : 'M';
  const c5 = scores.expression < 0 ? 'D' : 'A';  // 🆕
  return `${c1}${c2}${c3}${c4}_${c5}`;
}
```

**验收标准**：
- 单元测试覆盖 32 种 signKey 组合路径
- `calculateScores` 对 15 道计分题返回 5 个维度值
- 边界条件：全部选 D 方向 → 编码 `CSDD_D`；全部选 A 方向 → `EGPA_A`
